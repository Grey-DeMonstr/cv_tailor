# Examples

`sam-sample/` is a complete run for a fictional candidate. The person, the employers, the contact
details and the vacancy are all invented.

- `sam-sample/data/sources/` — the documents Sam started with: a CV, a LinkedIn export and an old
  cover letter.
- `sam-sample/data/` — the fact base the `onboard` skill built from them.
- `sam-sample/jobs/` — one application written by the `get-cv` skill. Start with `notes.md`.

Nothing here was written by hand. It is the output of running the two skills, kept so you can see
what to expect. Agents: this folder is reference only and is never a source of facts.
