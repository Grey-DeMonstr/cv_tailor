# Skills

One `##` heading per category, chosen to fit the owner's own field. One skill per bullet, with the
evidence for it: where it was used, for how long, at what depth.

A skill shown in a role is listed here *and* stays in that role's bullets in `experience.md`. This
file is the index; `experience.md` is the evidence.

Depth is recorded honestly. "Used daily for six years" and "one small tool in 2023" are both
useful facts, and they are different facts.
